# Feature Specification: Fixes From First Real Use

**Status**: Draft | **Created**: 2026-11-03

From the first run on a real desktop, and a UI and accessibility audit.

- **FR-001** Logins can be created and edited from a session's own settings, including at creation.
- **FR-002** A login prompt offers to remember the login, saving it only once the device accepts it.
- **FR-003** Moving to a field selects its text.
- **FR-004** Enter answers a prompt.
- **FR-005** The sidebar can be hidden and brought back with visible controls.
- **FR-006** Quick connections that work are kept in a folder.
- **FR-007** No sequence of closing panes can leave a blank tab that cannot be closed.
- **FR-008** Window chrome meets WCAG AA contrast on every theme, and controls meet the 24 point minimum.
- **FR-009** State is not shown by color alone. Deleting asks first. Settings and closing a tab have visible
  controls, and a session can be connected from its settings.
